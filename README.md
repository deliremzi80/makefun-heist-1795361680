A complete, original, top-down stealth heist game built for make.fun's `best-heist-game` competition.

## Game Features
- **Stealth Mechanics:** Roaming guards with dynamic vision cones and line-of-sight tracking.
- **Security Surveillance:** Rotating surveillance cameras and laser tripwires protecting high-value vaults.
- **Loot Target & Alarms:** Infiltrate the bank, bag diamonds and gold bullion, and escape before the alarm meter reaches critical lockdown.
- **Pure Offline Canvas:** 100% self-contained static HTML5 Canvas/JavaScript running offline in any desktop browser.
